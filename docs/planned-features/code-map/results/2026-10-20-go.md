2026-10-20, base `44ccf7b`, working-tree extractor version 4. Windows x64 / Node 24.11.1; Docker Linux / Node
24.21.0. Bundled Electron 44.4.5 uses Node 24.21.0. Grammars were already pinned, hash-verified and licensed in
`resources/code-map/grammars.json`; no new dependency or toolchain was installed for language resolution.

Go extraction covers functions, methods/receivers, types/aliases, structs/interfaces, fields, constants and variables;
Unicode uppercase names determine exports. Build directives are retained as symbol metadata, not evaluated. Package
directories, `go.mod` and contained `go.work use` entries resolve imports; other imports are external package nodes.
Declared locals/parameters and composite literals support direct receiver calls. Interface dispatch, dot imports,
unknown/nested receivers and generic inference stay unresolved. Duplicate build variants/modules do not pick an
arbitrary target. Test-only declarations never become production import targets. `vendor` is excluded.

declared/composite receivers, interface dispatch, parameter shadowing and tests. Calls: **7 TP / 0 FP / 0 FN** against
the manually declared reference; 4 unresolved calls match the expected negative cases. This measures the fixture,
not general Go accuracy. Reversed enumeration/config order and BOM/CRLF-normalized extraction are deterministic;
Unicode columns, syntax recovery and external modules are tested. No Go binary, package restore, LSP or project code
executes during indexing.
