# Stage 09: Code Map Visualizer

Implemented `oxytocin.code-map-visualizer` using public Plugin API 0.2.0 only. Project-singleton panel `codeMap.view`
and command `codeMap.open` expose Overview, File, Neighborhood and Search. Core project menu and Code Map settings
open the plugin when enabled. Disabled maps link to the allowlisted `oxytocin.codeMap.openSettings` core command.

Cytoscape.js 3.34.4 (MIT) is bundled locally. The bounded projection uses a deterministic preset grid; groups are
aggregated nodes, not thousands of compound children. Surviving positions and manual dragging persist across refreshes.
No force layout or continuous animation runs. The renderer supports compound nodes if future projections need them;
no layout extension or WebGL is required here. See the [official API](https://js.cytoscape.org/) for renderer/layout
capabilities. SVG/PNG export and Changes/Impact are intentionally left to stage 10.

## Headless Chromium spike

Windows, Node 24.16.0, Chromium Headless Shell 153.0.8010.12, i5-14400. Reproduce with
`npx tsx scripts/code-map-renderer-benchmark.ts` after installing Playwright Chromium. The opaque sandboxed iframe
loads local Cytoscape with CSP; no remote assets. Fixture includes cycles, hubs, long labels and 20 label-update
bursts. One run, not a population estimate. Raw measurements are in `2026-10-20-renderer.json`.

| Nodes / edges | First usable, ms | Programmatic pan to frame p95, ms | Idle frame cadence, FPS | JS heap, MiB |
| --- | ---: | ---: | ---: | ---: |
| 50 / 100 | 68.3 | 18.6 | 60.1 | 8.4 |
| 150 / 300 | 112.4 | 19.6 | 60.5 | 12.1 |
| 500 / 1000 | 277.2 | 36.0 | 60.2 | 26.2 |

The pan timing is a scripted update followed by requestAnimationFrame, not physical input latency. FPS is idle frame
cadence, not sustained animated pan performance. Heap is Chromium's usedJSHeapSize, not process RSS or native canvas
memory. No errors occurred. These numbers support a bounded nonanimated canvas view; they do not establish the
terminal-regression gate. No alternate renderer was needed for this prototype.

## Validation and remaining gates

- Shipped plugin assets build through the existing plugin bundler/checksum pipeline. A separate real-browser smoke
  (`npx tsx scripts/code-map-visualizer-smoke.ts`) loads the built view in an opaque sandbox, enforces CSP/connect-src
  none, uses the public SDK protocol and verifies search, keyboard selection, neighborhood, source locator delivery,
  invalidation, visibility cancellation and project switching. No page errors or external requests. It supplies a
  deterministic shell/backend fixture; it does not replace testing the Electron app.
- Unit behavior tests cover stale response rejection, identity switching, stable position allocation, cancellation
  on hidden views and avoiding read-audit invalidation loops. Public API/parser integration is covered by stage 08.
- App E2E is added as `tests/e2e/code-map-visualizer.spec.ts` but not executed. Docker is absent and WSL has no installed
  distribution. The user authorized commits after available checks and documenting missing Electron E2E.
- Full check/build logs: `test-results/code-map-stage09-check.log`, `code-map-stage09-build.log`. Notices regenerated
  for the current Windows installation, including Cytoscape. Its root production dependency is declared so license
  checks include the renderer dependency as well as the plugin workspace.
- Final validation passed: full check (1,371 unit, 68 integration and 3 latency tests; 4 unit and 66 platform/resource
  integration skips), build and final shipped-asset iframe smoke. Electron app E2E remains unexecuted.
- Still unmeasured: packaged Electron iframe/installer behavior, actual terminal p95 with/without the view, sustained
  interaction/memory under app load, production contrast/accessibility review. Do not mark those release gates passed.
- No models or paid tokens were used. Stage 10 and stage 14 need a corpus/harness only in this handoff; the user will
  perform paid measurements. Automatic learnings mode must remain unavailable until its evaluation gate passes.
