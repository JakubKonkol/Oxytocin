Claude Code Bridge

Claude Code can tell Oxytocin exactly what it is doing — working, waiting for your permission or finished — through hooks. Without them Oxytocin infers the state from Claude Code's session files and terminal output.

What installing does

  • Adds the oxytocin-bridge plugin (from a local marketplace named oxytocin) to your Claude Code user settings with claude plugin install.
  • Its hooks send prompt submissions, tool completions, permission requests, notifications and turn ends to http://127.0.0.1 on this computer. Oxytocin reads only the event type, the session id and the notification type; it stores nothing.
  • Only terminals opened in Oxytocin carry the secret token the endpoint requires. Claude Code sessions started elsewhere try the address too and ignore the failed request.
